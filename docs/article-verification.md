# Первая статья Writing — проверка

Проверено локально 23 октября 2026 года на production-сборке. Статья доступна по `/articles/design-the-second-attempt/`. В Writing ровно одна запись: **Design the second attempt**. Оба заголовка-заглушки отсутствуют в сгенерированных страницах. Файлов статей-заглушек в коллекции не было.

## Изменённые файлы

| Файл                                                | Изменение                                                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `src/content/articles/design-the-second-attempt.md` | Новая опубликованная статья; предоставленные метаданные и текст без редакторских дополнений             |
| `src/pages/articles/[...id].astro`                  | Статические маршруты через `getPublishedArticles()` и серверный рендер Markdown/MDX                     |
| `src/layouts/ArticleLayout.astro`                   | Заголовок, дата UTC, текст и ссылка домой; существующие Inter, цвета, системная тема и колонка 600px    |
| `src/pages/index.astro`                             | Writing из того же `getPublishedArticles()`; название и ID из коллекции                                 |
| `src/data/homepage.ts`                              | Удалён отдельный массив Writing с двумя заглушками                                                      |
| `src/components/ContentRow.astro`                   | Внутренние ссылки в той же вкладке; внешние сохраняют `_blank` и `noopener noreferrer`                  |
| `scripts/verify-content.mjs`                        | Изолированные проверки настоящих маршрутов и Writing: порядок публикаций, отсутствие черновиков         |
| `scripts/verify-output.mjs`                         | Ровно две HTML-страницы, полный текст статьи, отсутствие заглушек; showcase-проверки только для главной |
| `scripts/verify-browser.mjs`                        | Матрица статьи, переходы, refresh, фокус, no-JS и регрессия главной; новая папка доказательств          |
| `README.md`                                         | Актуальная архитектура Writing, маршрутов и инструкция проверки                                         |

Новые доказательства находятся в `docs/article-verification/`. Исходная рабочая копия была полностью untracked; существующие файлы сверены по SHA-256 с копией, сохранённой перед редактированием. Изменены только семь перечисленных существующих файлов; три файла реализации добавлены. Остальные исходные файлы и прежние материалы проверки сохранены побайтово. `package.json`, `pnpm-lock.yaml`, установленные версии, конфигурация Astro и Figma не менялись. Коммитов, push, deployment и изменений удалённых настроек не было.
