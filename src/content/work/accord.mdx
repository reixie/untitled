## Start with the company directory

Before a call, a small team can use the directory to compare companies in one view.

## Design process

1. Separate records from tools so the company directory stays easy to find alongside tasks, meetings, and notes.
2. Reuse cells with stable columns for names, domains, categories, and headcount.
3. Use Figma variables to keep the same layout in Light and Dark.

In the static Light mockup, Ramp is in row one and Stripe is in row eight. Both show Fintech. The tag is first and blue for Ramp, second and violet for Stripe. Keep the text label and use a consistent color for each category.

## Competitive analysis

- Attio’s configurable columns suggest keeping comparison fields visible by default. See [table views](https://attio.com/help/reference/managing-your-data/views/create-and-manage-table-views) and [record activities](https://attio.com/help/reference/managing-your-data/records/add-record-activities).
- HubSpot’s saved filters suggest a way to repeat the same comparison before recurring calls. See [saved views](https://knowledge.hubspot.com/records/create-and-manage-saved-views) and [record activities](https://knowledge.hubspot.com/records/manually-log-activities-on-records).
- Pipedrive’s organization detail suggests grouping related tasks, meetings, and notes in an Accord company view. See [data organization](https://support.pipedrive.com/en/article/how-is-pipedrive-data-organized) and [detail views](https://support.pipedrive.com/en/article/detail-view).
